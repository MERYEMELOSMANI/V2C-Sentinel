# Noncanonical legacy outputs

This folder contains outputs created before the unified policy experiment and the cloud-confirmation policy experiment were given separate output directories. The files may contain a configuration from one script and summary data from another. They are retained for traceability only and must not be used as evidence in the paper.

Use `results/final_two_level/` for the current paper. Re-run `run_unified_experiment.py` to create a clean `results/final/` policy-comparison result set, or run `run_cloud_confirmation_experiment.py` to create `results/cloud_confirmation/`.
