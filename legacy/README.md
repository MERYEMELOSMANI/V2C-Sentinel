# Legacy material

This directory preserves superseded experiments and one-off manuscript tools for traceability. Nothing here is part of the current paper's evidence chain.

- `scripts/` contains preliminary replay, sampling, audit, and report-generation programs.
- `results/` contains their corresponding tables and narrative reports.
- `paper_tools/` contains one-off document-editing helpers.
- `paper_versions/` contains superseded outlines and manuscript versions.

The old files are retained because they document how the project evolved. Use the canonical commands in the repository `README.md` for current work.
